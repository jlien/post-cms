## Context

`~/Eng/post-cms` (your cwd) is a git-based, static-first publishing stack
built as a reference architecture: content as files in git (meta.yaml +
index.mdx per folder), a Rust static build (Tera + pulldown-cmark) emitting
dist/ with search index + embeddings + MCP discovery artifacts, an Axum
origin server, and MCP servers both local (stdio, write ops) and public
(read-only POST /mcp). It was built to test a thesis: post-AI, a custom
agent-first stack beats renting a blogging platform (WordPress/Sanity).
Recent additions: typed collections with schema validation, propose_change /
propose_template review flow (branch -> PR with preview command), and
per-tenant git worktrees for concurrent agents.
