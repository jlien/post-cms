This site is built with **Post-CMS** — a git-based publishing stack.

There is no CMS database and no hosted platform. Posts and pages are files in a
git repository; a Rust crate builds them to static HTML; an MCP server handles
content operations and commits every mutation.

What that buys you:

- **Ownership.** The content is a git repo — forkable, greppable, diffable.
- **Speed.** Static HTML with inlined, minified CSS. No runtime, no plugins.
- **Cost.** Static files on any host, media on object storage. No per-seat
  pricing, no hosting tiers.
- **AI-friendly.** The whole stack is text an agent can read and edit — this
  page included.

Want the details? Every post under [the blog](/blog/) was written, built, and
published through the same pipeline you are reading right now.
